1. Extract this package and start a fresh Claude chat.
2. Paste REVIEW_PROMPT.txt into the chat and attach PAPER_CURRENT.pdf.

   authoritative for mathematics, layout, figures, tables and page citations.
3. Supply source/, code/ and evidence/ for the deeper mathematical, numerical,
   literature and reproducibility checks. If an upload does not accept a ZIP,
   upload the extracted files needed for each phase.
4. Keep optional_history/ and the historical review documents inside the full
   scientific snapshot unopened until Claude has written its initial review.
   A separate AI review is additional scrutiny, not human peer review.

VERIFY THE PACKAGE
From the extracted package directory, run:
    python3 VERIFY_PACKAGE.py
This uses only the Python standard library and does not rerun experiments.

REBUILD JUST THE CURRENT PAPER
The source/ directory is flat and contains all 13 manuscript inputs.
With a TeX distribution providing the packages named by the paper, run:
    cd source
    pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error nsp_contraction_paper_ieee
Repeat until references are stable (the saved clean check used three passes).
Inspect the resulting PDF and log. Source files and any rebuild outputs should
be copied elsewhere first if you want to keep the review package unchanged.

REPRODUCE THE FULL SCIENTIFIC PIPELINE
Work outside the extracted review-package directory:
1. Extract reproduction/neurosymbolic-reproduction-v1.1.1.zip.
   Its project folder is neurosymbolic-reproduction-v1.1.1/ and is runnable
   directly, with the final manuscript already in paper/.
2. Run python3 VERIFY_CURRENT_REPRODUCTION.py in that project directory.
   It checks the current overlay and preserved original scientific archive.
3. Follow that project's README.md to create a Python 3.12 environment with
   requirements-lock.txt and install a suitable TeX distribution. The recorded
   reference Python is 3.12.7; dependency/platform differences can alter results.
4. From that project root, run:
   OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 python run_all.py
   The optional --parallel-science flag overlaps independent producers.
   This is a new full run and can overwrite its project's saved results.
5. The separate reproduction/neurosymbolic-reproduction-claude-revision.zip
   preserves the original twelve-stage run, including its earlier manuscript.
   Inspect it for provenance rather than confusing it with PAPER_CURRENT.pdf.
